Colors

Click a color to change it. Use a solid color or a gradient, and type any hex like #3fd68a or #00000080 (the last two digits are opacity).

Shortcuts

⌘⇧Space
Go / Pause, from any app
⌘⇧↩
Done: finish the task, start the next
⌘⇧N
Add a task
⌥⇧⌘Space
Show or hide the timer

Drag the timer's bottom-right corner to resize it. Hover it for the hide (–) and quit (×) buttons.
